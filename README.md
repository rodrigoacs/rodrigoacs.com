# rodrigoacs.com

Welcome to the repository for my personal website, a project designed to be my digital portfolio, where I showcase my professional journey, projects, and share knowledge through an integrated blog.

**Access the website at: [rodrigoacs.com](https://rodrigoacs.com/)**

## ✨ Overview

This project was created to be a centralized space for my professional and academic activities. Here, you will find:

  * **Project Portfolio:** A showcase of my most relevant work.
  * **Personal Blog:** A space to share articles, tutorials, and insights on software development and technology.
  * **Interactive CV:** An online and always-updated version of my resume.
  * **Modern and Responsive Design:** A pleasant and adaptable interface for different devices.

## 🚀 Key Features

  * **Internationalization:** Support for multiple languages (English and Portuguese) to reach a global audience.
  * **Dynamic Theme (Light/Dark):** Automatic adaptation to the user's system theme, with the option to switch manually.
  * **SEO Optimized:** Meta tags for better search engine indexing and social media sharing.
  * **Dynamic Project Cards:** Integration with `github-readme-stats` to display information from my repositories with themes that adapt to the site.

## 🛠️ Technologies Used

This project was built with the following technologies:

  * **Vue.js:** A progressive framework for building user interfaces.
  * **Vite:** A modern build tool that provides a faster development experience.
  * **Vue Router:** For managing the application's routes.
  * **Vue I18n:** For the internationalization of the site.
